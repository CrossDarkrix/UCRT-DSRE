FFmpeg / LAME build and relinking information

Versions
- FFmpeg: 9.0.2
- LAME: 3.100
- Android minimum API: 23
- ABIs: arm64-v8a, armeabi-v7a

License profile
- LGPL-oriented build
- --enable-gpl is not enabled
- --enable-version3 is not enabled
- --enable-nonfree is not enabled
- FFmpeg is shipped as ABI-specific shared libraries
- LAME is built as libmp3lame.a and statically linked into shared libavcodec.so

Bundled FFmpeg shared libraries
- libavutil.so
- libswresample.so
- libswscale.so
- libavcodec.so
- libavformat.so

Enabled DSRE output encoders
- ALAC
- FLAC
- AAC
- libmp3lame
- PCM
